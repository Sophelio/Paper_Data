# Heat Equation Degeneracy

Dalia project for the analytic heat-equation degeneracy example.

- `data/realization_00.parquet` — one realization (`times`, `x`, `t`, `u`, derivatives, `kappa`, `mode`)
- `data_provider.py` — Dalia `get_provider()` contract (parquet stems are record ids)

Open **Heat Equation Degeneracy** from Dalia Home, then reload the provider if needed.
